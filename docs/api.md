# API reference

The supported public API is exported from `profanex`. Construct a `Filter` once and reuse it; configuration and compiled filters are immutable after construction.

For configuration recipes and tradeoffs, see the [configuration guide](configuration.md). For normalization and matching semantics, see [How Profanex works](how_it_works.md).
